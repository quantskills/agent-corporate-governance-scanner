#公司治理综合评分 Agent / Corporate Governance Scanner Agent

## 项目概述 / Overview

输入一个股票代码，输出 0–100 的治理风险评分 + 逐项证据链 + 行业对比。
数据来自 PandaData 真实接口，自然语言归纳来自 DeepSeek LLM。

Input a stock code, output a 0–100 governance risk score with itemized evidence chain and industry comparison.
Data comes from PandaData real APIs; natural language summary is generated by DeepSeek LLM.

## 9 个治理维度 / 9 Governance Dimensions

| 维度 | 权重 | 说明 |
|------|------|------|
| 审计意见 / Audit Opinion | 15 | 审计机构与意见类型 |
| 诉讼风险 / Litigation | 15 | 法律诉讼与仲裁 |
| 违规记录 / Violation | 15 | 监管处罚与违规 |
| 关联交易 / Related Party | 12 | 关联交易金额与频率 |
| 担保风险 / Guarantee | 12 | 对外担保与质押 |
| 股权性质 / Equity Nature | 10 | 大股东持股与性质 |
| 合同风险 / Contract | 8 | 重大合同风险 |
| 中介机构 / Intermediary | 8 | 审计/律所/评估机构 |
| 举牌收购 / Acquisition | 5 | 举牌与股权变动 |

## 快速开始 / Quick Start

```bash
pip install openai python-dotenv panda_data
# 配置 .env（OPENAI_API_KEY + PANDA_DATA 凭据）/ Configure .env
python main.py --symbol 000001.SZ           # 文本报告 / Text report
python main.py --symbol 600519.SH --json    # 结构化 JSON / Structured JSON
python main.py --symbol 002594.SZ --agent   # 完整 Agent + LLM 归纳 / Full agent with LLM
python main.py --selftest                   # 离线自检 / Offline self-check
```

## 风险等级 / Risk Levels

| 分数 / Score | 等级 / Level |
|-------------|-------------|
| ≥85 | 优（低风险）/ Excellent (Low risk) |
| 70–84 | 良（中低风险）/ Good (Low-medium risk) |
| 55–69 | 中（中风险）/ Fair (Medium risk) |
| 40–54 | 差（高风险）/ Poor (High risk) |
| <40 | 极差（极高风险）/ Very poor (Very high risk) |

## 已知限制 / Known Limitations

- PandaData 未提供 A 股诉讼/担保/合同的专用接口，这些维度使用行业中性默认值
- PandaData does not provide dedicated APIs for A-share litigation/guarantee/contract; these dimensions use industry-neutral defaults
- LLM 归纳会消耗 DeepSeek 额度 · LLM summarization consumes DeepSeek quota
